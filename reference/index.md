# Package index

## Data Retrieval

Retrieve data from specified FDIC BankSuite API endpoints

- [`get_demographics()`](https://ketchbrookanalytics.github.io/fdic/reference/get_demographics.md)
  : Retrieve Summary of Demographic Data for FDIC-Insured Institutions
- [`get_failures()`](https://ketchbrookanalytics.github.io/fdic/reference/get_failures.md)
  : Retrieve Historic Bank Failure Data
- [`get_financials()`](https://ketchbrookanalytics.github.io/fdic/reference/get_financials.md)
  : Retrieve Financial Data for FDIC-Insured Institutions
- [`get_history()`](https://ketchbrookanalytics.github.io/fdic/reference/get_history.md)
  : Retrieve Data on Structural Change Events for FDIC-Insured
  Institutions
- [`get_institutions()`](https://ketchbrookanalytics.github.io/fdic/reference/get_institutions.md)
  : Retrieve Financial Institutions
- [`get_locations()`](https://ketchbrookanalytics.github.io/fdic/reference/get_locations.md)
  : Retrieve Financial Institution Locations
- [`get_sod()`](https://ketchbrookanalytics.github.io/fdic/reference/get_sod.md)
  : Retrieve Summary of Deposit (SOD) Data for FDIC-Insured Institutions
- [`get_summary()`](https://ketchbrookanalytics.github.io/fdic/reference/get_summary.md)
  : Retrieve Historical Aggregate Data by Year for FDIC-Insured
  Institutions
